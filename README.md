# 中国联通江苏资费工作台

Jiangsu Unicom Tariff Workbench · 离线单页应用

自动抓取**中国联通官方资费专区（江苏）**的套餐数据，以可视化工作台的形式监控资费套餐的上线、下线与变更。参考站点：中国移动资费监控页（hnvip.qd.je）的模式——定时抓官网 → 更新仓库 → 发布静态页面。

## 功能特性

- **自动联网更新**：每日定时抓取联通官方资费专区（江苏·移网）最新套餐数据，自动更新本仓库
- **KPI 总览**：在架套餐总数、本省/全国资费数量、类别覆盖、月费区间、数据基准时间
- **可视化分析**：类别分布、价位区间分布、归属占比、价格 Top10、最低价 Top10
- **资费变更时间线**：套餐上线 / 下线 / 手动变更记录
- **套餐明细表**：筛选、排序、分页浏览全部套餐；点击查看完整资费标准（语音、流量、短信、定向流量、权益、退订方式等 29 个字段）
- **手动录入**：「＋新增套餐」手动补充任意套餐（本地保存），支持导入 / 导出 JSON（合并 | 替换）
- **零依赖**：单 HTML 文件，CSS/JS 全部内联，可离线打开

## 快速开始

直接用浏览器打开 `index.html` 即可（数据已内嵌 SEED_DATA，离线可用）。部署到 GitHub Pages 后也可在线访问。

## 数据说明

- **数据来源**：中国联通官方资费专区 `https://img.client.10010.com/zifeizhuanquwt/index.html`（江苏·本省资费·套餐>移网）
- **数据范围**：江苏省内可办理的移网套餐（含全省通用及地区停售差异说明，如"盐城/南通停售"）
- **数据字段**：套餐名称、方案编号、资费标准、超出资费、其他费用、语音、通用流量、短信、定向流量、IPTV、带宽、权益、其他服务内容、适用范围、有效期限、销售渠道、在网要求、退订方式、违约责任、上线/下线日期、其他事项等 29 个字段
- **更新机制**：每日 22:30 自动抓取更新（本地定时任务 → 更新 `packages.json` 与 `index.html` 内嵌数据 → 推送本仓库）

## 文件结构

```
├── index.html            # 工作台（数据内嵌，单文件可离线打开）
├── packages.json         # 结构化套餐数据（工作台数据源）
├── js_plans.json         # 浏览器抓取的原始数据
├── convert_plans.py      # 原始数据 → packages.json 转换脚本
├── inject_seed.py        # packages.json → index.html SEED_DATA 注入脚本
└── README.md
```

## 数据更新

`packages.json` 的 `meta` 字段记录了抓取时间（`crawledAt`）、数据基准时间（`asOf`）、来源与数据范围。每次自动抓取后工作台会自动反映最新数据基准。
